# Review: S2b-commit-tactics — logic (pass 2)

Method: every worked example (E1-E8) was recomputed by hand and in a scratch script (`/tmp/claude-0/s2a.py` for the S2a scores the pipeline feeds into S2b). E1, E2, E3(a)(b)(d) timings, E4 (ttk 50/72/36, tiers), E5 (satGain 6/12.8, the 52-tick boundary at 15.0/15.1, overflow rule), E6 (`U 0.3917`, prior 0.50, rng call counts) and E7 (`U 0.4949`, win at tick 260, loss damage 9 and ticks 40, decay 15.5) all reproduce. The findings are logic faults in the pipeline S2a -> masks -> hysteresis -> targets, not arithmetic. D31 items touching S2b: "owner-feet fallback" is not S2b's (S4b); nothing open for S2b. Decided rows (D1, D3, D5, D15, D22, D23) were not re-raised, except that item 3 is a contradiction with D15 itself.
