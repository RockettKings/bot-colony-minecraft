| 1 | major | §5.1 line 843 `weaponScore = damage + (sharpness ? 0.5 + 0.5*level : 0)` | This is the Java 1.9+ sharpness formula. Bedrock Edition adds 1.25 damage per level (I = 1.25, V = 6.25). With the Java formula, a sharpness V stone sword (5 + 3 = 8) outranks a plain diamond sword (7) while in Bedrock it deals 11.25. Ranking is wrong whenever sharpness is involved. | Replace with: `weaponScore = damage + 1.25 * sharpnessLevel` (Bedrock; `sharpnessLevel` = level of `"sharpness"` in `ItemStackView.enchants`, 0 if absent). Update any unit-test expectation derived from the old formula. |
