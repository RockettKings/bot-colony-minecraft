# Review: S3-body — logic

| # | Severity (blocker/major/minor) | Location (§ / line) | Problem | Exact fix (replacement text, number, or decision) |
|---|---|---|---|---|
| 1 | blocker | §1.2 step 7 (line-of-sight ray) | `getEntitiesFromRay` from the eye position includes the bot itself (a never-target player) at distance 0. The "friendly in ray" check therefore always finds a friendly entity first, so every attack returns `no_los` and the bot never attacks. | Replace step 7 text with: "Ignore ray hits where `entity.id === p.id` or `distance <= 0.3`. The first remaining hit decides: target id matches means clear; any other entity means `no_los` (never-target) or `blocked_by_other`." |
| 2 | major | §3.3.11 retreat total cap vs P0 step 5 REGEN | Retreat tactic total cap is 600 ticks, but P0 step 5 REGEN waits up to 1200 ticks. The retreat is cut off at 600 while regeneration still needs time, so the bot returns to FIGHT at low HP. | Add `retreatTotalCapTicks = 1500` to §7 and use it as the retreat cap; state "REGEN is exempt from the 600 phase cap and is bounded by `retreatTotalCapTicks`". |
| 3 | major | §4 `eatStatus` | The use/stop event handler does not compare the event item typeId with the item being eaten. `lowerShield` calls `stopUsingItem` on the shield, which fires a stop event for the shield and is read as an interrupted meal, aborting a valid eat. | Handler condition: `ev.itemStack.typeId === eating.typeId && ev.source.id === p.id`. Capture `before.tick` after `lowerShield()` returns. |
| 4 | minor | §3.3.4 hit_and_back_off | BACKOFF distance is 3 blocks but the age-12-tick movement only covers 2.6 blocks, so the phase ends before the bot reaches the target distance and re-attacks inside reach. | Change BACKOFF age threshold from 12 to 16 ticks (covers 3.4 blocks at 0.215 blocks/tick). |
| 5 | minor | §3.3.7 break_line_of_sight DASH | From long range with no closer cover, DASH picks cover farther than the threat distance and runs toward the enemy. | Add precondition: "If the nearest cover is farther than D=10 or closer to the threat than the bot, return FAIL (`no_cover`) and hand off to the next tactic." |
| 6 | minor | §3.3.11 retreat RUN home choice | RUN picks the home direction without checking that the straight path passes a threat; the bot can run through the enemy. | Add: "Reject a RUN path whose segment passes within 8 blocks of any hostile; fall back to the next tactic then." |
| 7 | minor | §3.3.12 flee_sneak vs S1 §9.3 | flee_sneak for the warden is unreachable because the S1 warden reflex always takes over first. | Note in §3.3.12: "flee_sneak only runs when the warden reflex is disabled (`config.reflex.wardenEnabled=false`); otherwise the reflex owns warden handling." |
| 8 | minor | §3.3 knockback retreat | Retreat of 7 blocks in 25 ticks needs 0.28 blocks/tick, above the sprint speed 0.28 only with no turn cost; unrealistic. | Replace with 6 blocks in 40 ticks. |
| 9 | minor | §3.3 AIR phase age base | AIR phase age is counted from the JUMP command but the JUMP pump takes up to 3 ticks to leave the ground, so the phase ends while still grounded. | Count AIR age from the first tick where `isOnGround === false`. |
| 10 | minor | §1.2 `lastStrikeAt` | Initial value unspecified; `now - lastStrikeAt` is NaN on first attack, so the first cooldown check can block the strike. | Initialize `lastStrikeAt = -1000`. |
| 11 | minor | §3.3.2 melee_strafe | Abort condition wording ("if it doesn't work") is vague. | Replace with: "Abort and FAIL after 60 ticks without a landed hit, or if distance stays above reach+1 for 20 ticks." |
| 12 | minor | §3.3.11 REGEN | With hunger below 18 and no food, REGEN waits the full 1200 ticks with no recovery. | Add: "If `hunger < 18` and no edible item exists, finish REGEN immediately as DONE." |
| 13 | minor | §3.3.9 avoid_path_around | HOLD phase has no cap if the mob blocks the path indefinitely. | Add `avoidHoldMaxTicks = 200`; after that return FAIL (`blocked`). |
